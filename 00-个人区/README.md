# 📥 个人区

这里是**你随手写的地方**。放进来就行——不用分类、不用补 frontmatter、不用起好名字。

## 目录规则

**一人一格**：`00-个人区/<你的名字>/`

| 你的名字 | 你的格子 |
| --- | --- |
| 史荣新 | `00-个人区/史荣新/` |

> 为什么必须按姓名分？因为将来接权限系统时，授权是按**路径**做的。
> 路径里没有名字，就没法表达"只能写自己那份"。

## 写进这里意味着什么

**写进个人区 = 声明"这条我给团队看"。**

所以：

| ✅ 可以放 | ❌ 不要放 |
| --- | --- |
| 思考过程、调研碎片、会议速记 | 私事、牢骚 |
| 半成品、没想清楚的想法 | 内部人事评价 |
| 从别处抄来待整理的料 | 客户敏感信息 |
| 随手记的实验记录 | API key、密码、Token |

个人区**不会**被发布到站点（它在 `01-公共区/` 之外，结构上不可能上线）。
但内容会被 AI 搬进正式区——那一刻它就公开了。

## AI 会做什么

1. 读取你格子里的内容
2. 判断成型程度与归属，**移动**（不是复制）进正式区对应目录
3. 补全 frontmatter、统一命名、建双链、把图片收进 `_附件/`
4. 在你的 `_去向.md` 里追加一行：日期 / 原标题 / 新位置

**AI 不会删你的东西。** 也不会留副本（避免两个真相）。

## `_去向.md`

每次 AI 从你格子里搬走内容，都会在这里留一行。东西找不到了，看这个文件。

| 日期 | 原标题 | 新位置 |
| --- | --- | --- |
| 2026-09-18 | （示例）screenshot-to-code 调研 | `01-公共区/10.领域知识/01.研发/技术调研/` |
