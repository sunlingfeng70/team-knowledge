# 📚 团队知识库

欢迎来到团队唯一的文档知识库。这里沉淀项目、领域知识和参考资料，所有内容以 Git 管理。

> ⚠️ **本仓库公有可见**：任何人可读。**绝不提交**密钥、密码、Token、内部敏感数据。
>
> 🌐 站点：<https://sunlingfeng70.github.io/team-knowledge/>（**已改为手动发布**，需要上线时到 Actions 点 Run workflow）

### 个人区（**不会公开**）

| 目录 | 用途 |
|------|------|
| `00-Inbox/<你的名字>/` | 随手记。不分类、不补字段、不用起好名字 |

> 个人区在 `content/` **之外**，结构上不可能被发布。写进去就等于声明"这条准备给团队看"——
> 所以**私事、牢骚、内部人事、客户敏感信息不要放这里**。
> AI 会把成型内容搬进正式区，并在你的 `_去向.md` 里留一行记录。

## ✍️ 新成员三步

1. **装好环境** —— 见仓库根目录 `README.md`（clone、Obsidian Git 插件、PAT、自动同步）
2. **把东西丢进** `00-Inbox/<你的名字>/` —— 其他什么都不用管
3. **等 AI 整理** —— 分类、命名、加字段、建链接、收附件，全都不是你的活

写得正式的内容也可以**直接写进正式区**。不确定放哪就丢个人区。

## 📐 两条约定

- **文件名**：说人话，让一眼看懂。别用 `新建文档 1`。
- **不加日期前缀**：日期交给 frontmatter 的 `created`，文件名只放主题。
